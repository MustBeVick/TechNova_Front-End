# TechNova
A TechNova é uma plataforma desenvolvida para conectar empresas e clientes, facilitando a busca, consulta e compra de produtos e materiais. O sistema integra funcionalidades de vendas e estoque, proporcionando uma experiência mais organizada e acessível.

Este é o repositório destinado ao desenvolvimento da camada front-end da plataforma TechNova, responsável pela interface gráfica e pela interação dos usuários com o sistema.

Contempla a estruturação das páginas, navegação, formulários, catálogo e consulta de produtos, carrinho de compras, acompanhamento de pedidos e interfaces administrativas. Também abrange aspectos de responsividade, acessibilidade e experiência do usuário.
